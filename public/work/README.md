# Selected Work Assets (`/public/work`)

Place your project media files (images, GIFs, or short loop videos) in this folder.

### Supported Formats
- **Images / GIFs**: `.gif`, `.png`, `.jpg`, `.jpeg`, `.webp`
- **Videos**: `.mp4`, `.webm`

### Tips
- **Aspect Ratio**: 4:3 or 16:9 works best.
- **Videos**: Video files are automatically set to `autoPlay loop muted playsInline`.
- **Kott Style**: Kott uses `object-contain p-3` inside a 46vh bordered frame.
